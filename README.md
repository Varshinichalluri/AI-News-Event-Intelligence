
# AI News Event Intelligence

An AI-powered news analytics project that collects AI-related news articles, groups similar articles into events, builds event timelines, and displays insights through an interactive Streamlit dashboard.

## Features

- Collect AI-related news using Google News RSS.
- Extract and preprocess article text.
- Generate semantic embeddings using Sentence Transformers.
- Cluster similar articles into events.
- Assign unique event IDs and analyze similarity.
- Build event timelines.
- Generate template-based event summaries.
- Explore events and articles through a Streamlit dashboard.

## Tech Stack

- Python
- Pandas and NumPy
- Sentence Transformers
- Scikit-learn
- Streamlit
- BeautifulSoup
- Trafilatura

## Installation

Clone the repository:

```bash
git clone https://github.com/Varshinichalluri/AI-News-Event-Intelligence.git
cd AI-News-Event-Intelligence
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Project

Run the processing pipeline in order:

```bash
python -m src.data_collection.fetch_news
python -m src.embeddings.generate_embeddings
python -m src.clustering.cluster_articles
python -m src.timeline.build_timelines
python -m src.summarization.summarize_events
```

Launch the dashboard:

```bash
python -m streamlit run app/dashboard.py
```

## Current Results

In one recorded run, the project processed 100 articles and identified 72 event clusters from 83 sources. Results may vary with each collection run.

## Limitations

- Article extraction depends on publisher accessibility.
- Clustering quality depends on the collected articles and similarity threshold.
- Event summaries are template-based, not generated by an LLM.

## Future Improvements

- Integrate an LLM for richer event summaries.
